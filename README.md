## Getting Started

Use node version 20+

```bash
npm install
npm run dev
```

### Available Scripts

| Command             | Description                          |
| ------------------- | ------------------------------------ |
| `npm run dev`       | Start dev server on port 3000        |
| `npm run build`     | Type-check and build for production  |
| `npm run preview`   | Preview production build             |
